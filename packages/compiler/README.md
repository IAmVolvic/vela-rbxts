# @vela-rbxts/compiler

Native compiler for [`vela-rbxts`](https://github.com/astra-void/vela-rbxts).

Resolves, validates, and lowers Tailwind-style utility classes into Roblox UI props, and backs the editor APIs used by the standalone LSP (completions, hover, diagnostics). Distributed as a Rust N-API addon with prebuilt binaries per platform.

This package is an internal implementation detail of `vela-rbxts`. Install [`vela-rbxts`](https://www.npmjs.com/package/vela-rbxts) instead unless you are building tooling on top of the compiler API.
