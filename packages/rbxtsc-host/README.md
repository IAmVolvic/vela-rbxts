# @vela-rbxts/rbxtsc-host

Host adapter that bridges the [`vela-rbxts`](https://github.com/astra-void/vela-rbxts) compiler into the `rbxtsc` transform pipeline.

Filters eligible source files, resolves the nearest `vela.config.ts`, drives the native compiler, and surfaces compiler diagnostics through roblox-ts.

This package is an internal implementation detail of `vela-rbxts`. Install [`vela-rbxts`](https://www.npmjs.com/package/vela-rbxts) instead.
